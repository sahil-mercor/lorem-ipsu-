LOREM IPSUM

Open index.html in a browser to read the handbook. For the most reliable
clipboard behavior, use a local web server or deploy it to a secure URL.

HOST ON VERCEL
1. Extract this folder and put its files at the root of a Git repository.
2. Import the repository into Vercel as a new project.
3. Use the Other framework preset. No installation or build step is needed.
   The included vercel.json sets the output directory to the project root.
4. Deploy. The site has no server, database, environment variables, or API keys.

EDIT THE CONTENT
The handbook sections, onboarding checklist, templates, and source links
are in app.js. Edit styles.css for colors and layout, and index.html for
the page shell. No compilation is needed after changes.

FEATURES
Section search, anchor navigation, personal onboarding checklist saved in
browser local storage, expandable guidance, copyable templates, print layout,
and a responsive mobile layout.
